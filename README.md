## 👋 About Me

I'm **George Fernandez**, founder of **IndianBrand Technology** in Hyderabad.
I build software from first principles — including my own programming language.

- 🖋️ Creator of **[INK](https://github.com/uGeorgeFernandez/ink)**, a small, safe, compiled language
- ⚙️ Its whole compiler — lexer, parser, code generator — is hand-written in **x86-64 Assembly**
- 🎯 Goal: code that reads the way a person thinks, with native speed and memory safety
- 🇮🇳 Building technology made in India, for the world

## 🚀 Featured Project — INK

<table>
<tr>
<td width="55%">

**INK — Write the Future**

A beginner-friendly language that compiles to real native binaries via LLVM.

- 🛡️ **Memory-safe** — out-of-range list access is caught, not silently corrupted
- ✅ **Type-checked** — mistakes caught before the program runs
- ⚡ **Compiled** — fast native executables, not slow scripts
- 📖 **Readable** — `show`, `let`, `text`: words a beginner can guess

<a href="https://github.com/uGeorgeFernandez/ink"><img src="https://img.shields.io/badge/View%20Repo-INK-0b1f4d?style=for-the-badge&logo=github" alt="View INK" /></a>

</td>
<td width="45%">

```ink
show "Jai Hind!"

fn greet(name: text) -> text {
    return "Namaste " + name
}
show greet("George")
```

```
Jai Hind!
Namaste George
```

</td>
</tr>

**Compiler pipeline**

```
program.in → [ Lexer ] → [ Parser ] → [ Codegen ] → LLVM IR → clang → native binary
```
